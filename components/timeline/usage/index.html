Timeline

Timelines display a list of events in chronological order, showing the sequence and relationship between events over time.

UsageAPIPlaygroundAccessibility

9:00 Created

10:30 Reviewed

12:15 Approved

Usage

forge-timeline connects a series of forge-timeline-item children with a vertical line through their markers. Each item’s main content goes in its default slot, with start and end slots on either side, a marker slot for the indicator, and a detail slot below for extra context. Use forge-timeline-break between items to visually separate non-sequential groups. Reach for a plain list instead when order and time aren’t meaningful to the content.

Rules

Do
Include timing information — a date, a relative time, or a plain sequence — whenever when an event happened matters.Give each item enough detail to be understood on its own, without relying on neighboring items for context.Treat marker icons as decorative — put the information that actually matters in the item's own content, not the icon.
Don't
Don't use a timeline for content that has no real chronological or sequential relationship.Don't rely on marker color alone to communicate an item's status — pair it with text or an icon.

Basic usage

Each forge-timeline-item shows a default circular marker, and its main content goes in the default slot.

A timeline of items connected by a vertical line through their markers.

Icons

Slot a forge-icon into marker to replace an item’s default circular indicator. Treat the icon as decorative, since the item’s own content should carry the meaning.

Timeline items with an icon in the marker slot in place of the default marker.

<forge-timeline>
  <forge-timeline-item>
    <forge-icon slot="marker" name="check_circle">
    </forge-icon>

Sidebar lines

An item’s sidebar defaults to auto, which draws its connecting line above and below its marker, automatically omitting whichever side doesn’t apply to the first or last item. Set sidebar to start, end, both, or none to control this manually — useful for implying items exist before or after what’s actually rendered.

Each sidebar value on a timeline item: auto, none, start, end, and both.

PreviewCode
<forge-timeline>
  <forge-timeline-item>
    <span>
      Auto sidebars
    </span>
  </forge-timeline-item>
  <forge-timeline-item sidebar="none">
    <span>
      No sidebars
    </span>
  </forge-timeline-item>
  <forge-timeline-item sidebar="start">
    <span>
      Start sidebar
    </span>
  </forge-timeline-item>

      End sidebar

Timestamps

Place a timestamp as a direct child of the timeline to show it as a date heading for the items below it. Inside an item, a timestamp renders inline with the content, and separator adds a dot between them. Put item timestamps in the start slot when they should line up across items.

Timestamps as date headings between items, and as times before, after, or inside an item's detail.

PreviewCode
<forge-timeline>
  <forge-timestamp datetime="2024-03-15">
  </forge-timestamp>
  <forge-timeline-item>
    <span>
      Timestamp after
    </span>
    <forge-timestamp datetime="2024-03-15T14:30:00" format="HH:mm" separator="start">
    </forge-timestamp>
  </forge-timeline-item>
  <forge-timeline-item>
    <forge-timestamp datetime="2024-03-15T12:15:00" format="HH:mm" separator="end">
    </forge-timestamp>
    <span>
      Timestamp before
    </span>
  </forge-timeline-item>
  <forge-timestamp datetime="2024-03-14">
  </forge-timestamp>
  <forge-timeline-item>
    <span>
      No timestamp separator
    </span>
    <forge-timestamp datetime="2024-03-14T16:45:00" format="HH:mm">
    </forge-timestamp>
  </forge-timeline-item>
  <forge-timeline-item>
    <span>
      Timestamp in detail
    </span>
    <div slot="detail">
      Posted at
      <forge-timestamp datetime="2024-03-14T16:45:00" format="HH:mm">
      </forge-timestamp>
    </div>
  </forge-timeline-item>
</forge-timeline>

Structure

A timeline is rendered as a semantic list — role="list" on the timeline itself, role="listitem" on each timeline item — so assistive technology announces it as a real list of events, not arbitrary markup.

Markers and breaks

Marker icons should be decorative, since the surrounding item content already provides the necessary context — don’t make a marker icon the only place meaning lives. A forge-timeline-break is purely visual and is marked aria-hidden="true" for that reason; it carries no content of its own to announce.

Color contrast

When using theme to color a marker, make sure that color still meets WCAG contrast requirements against its background.
