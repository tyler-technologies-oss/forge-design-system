Time Picker

A time input component with an integrated dropdown for selecting time values, with support for various formats, masking, and validation.

UsageAPIPlaygroundAccessibility

Overview

Time pickers allow users to select specific time values through an interactive interface. They provide a structured way to input time data while reducing errors and ensuring consistent formatting across different time systems and locales.

Usage

forge-time-picker wraps a child text field and adds a dropdown of selectable time options, through use24HourTime, min/max/step, restrictedTimes, masked, and allowInput. Use it when a person is entering a specific time; for a time range, place two time pickers side by side. Reach for a select instead when the choice is really a vague description (“now”, “in 30 minutes”) rather than a specific time, or a plain text field instead when the value isn’t a time at all.

Rules

Do
Support both 12-hour and 24-hour formats depending on locale and context.Pair a 12-hour format with a visible AM/PM indicator.Place two time pickers side by side to capture a time range.Show a timezone alongside the value when the time is specific to a place or event.
Don't
Don't use a time picker for vague time descriptions like "now" or "in an hour" — use a select instead.Don't use a time picker for free-text entry that isn't actually a time — use a text field instead.Don't restrict input to the dropdown alone unless typing a time would be error-prone for your data.

Basic usage

A time picker’s text field accepts typed input and its trailing icon button opens a dropdown of selectable times.

A time picker combining a text field with a dropdown of time options.

PreviewCode
<forge-time-picker use-24-hour-time="false">
  <forge-text-field>
    <input id="time-picker" type="text" autocomplete="off" autocorrect="off" autocapitalize="off" role="combobox" aria-live="assertive" aria-atomic aria-haspopup aria-controls="forge-aria-controls-placeholder">
    <label for="time-picker" slot="label">
      Time
    </label>
    <forge-icon-button slot="trailing" density="medium" aria-label="Toggle time dropdown">
      <forge-icon name="clock_outline">
      </forge-icon>
    </forge-icon-button>
  </forge-text-field>
</forge-time-picker>

Format

Set use24HourTime to switch between the default 12-hour format and 24-hour time.

12-hour (default) and 24-hour formats.

  <forge-text-field>
    <label for="time-picker-12h">
      12-hour
    </label>
    <input type="text" id="time-picker-12h" />
  </forge-text-field>
</forge-time-picker>
<forge-time-picker use24-hour-time>
  <forge-text-field>
    <label for="time-picker-24h">
      24-hour
    </label>
    <input type="text" id="time-picker-24h" />
  </forge-text-field>
</forge-time-picker>

Working with values

Always use 24-hour format in code

Regardless of the display format shown to the user, every programmatic read or write of value — and the change event — uses 24-hour time (e.g. "15:30"). This keeps the format locale-independent. Set values through forge-time-picker itself, never the wrapped <input> (the input only takes cosmetic attributes like placeholder). If the field needs to be required or invalid, set that on the embedded forge-text-field, not on forge-time-picker.

const picker = document.querySelector("forge-time-picker");
picker.value = "15:30"; // always 24-hour, even if use24HourTime is false
picker.addEventListener("change", () => console.log(picker.value)); // also 24-hour

Constraints

Set min, max, and step to bound selectable times and control the interval between dropdown options.

A time picker bounded to a range, in 30-minute steps.

PreviewCode
<forge-time-picker min="09:00" max="17:00" step="30">
  <forge-text-field>
    <label for="time-picker-constrained">
      Appointment time
    </label>
    <input type="text" id="time-picker-constrained" />
  </forge-text-field>
</forge-time-picker>

Masking and input

Set masked to apply an input mask, shown as a placeholder, so typed times are corrected to a consistent format as the user types.

A masked time picker showing its format as a placeholder.

PreviewCode
<forge-time-picker masked show-mask-format>
  <forge-text-field>
    <label for="time-picker-masked">
      Choose time
    </label>
    <input type="text" id="time-picker-masked" />
  </forge-text-field>
</forge-time-picker>

Labeling

Add an aria-label to the <input> if you’re not pairing it with a <label for> — the time picker doesn’t infer one on its own.

Automatic ARIA attributes

The component applies role="combobox", aria-live, aria-atomic, aria-haspopup, aria-expanded, aria-controls, aria-activedescendant, and aria-disabled to the input for you, so you don’t need to set those yourself.

Keyboard interaction

As you arrow through the dropdown, the highlighted option is announced via aria-activedescendant.
