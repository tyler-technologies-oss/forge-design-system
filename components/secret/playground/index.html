Secret

Conceals sensitive content with a blur, mask, or noise effect, revealing it on user interaction.

UsageAPIPlaygroundAccessibility
123-45-6789

Overview

The secret component obfuscates sensitive data behind an effect (A blur, mask, or noise effect) in order to prevent data from being easily visible. This is helpful for data that is particularly sensitive and needs to be redacted in normal display, but can be toggled to show the hidden data when the user needs it.

Usage

forge-secret conceals its default-slot content until a user reveals it, through open, variant (blur, masked, or noise), block, buttonPosition, showOnHover, and name. Use it for sensitive values a user might not want visible by default, like an account number or password, in a context where someone else could be looking at the screen.

Not a security control

Concealed content is still present in the DOM and can be read from the page source — forge-secret only prevents visual exposure. It’s useful for shoulder-surfing and accidental-glance protection, but it does not protect against a determined user. The only way to truly secure sensitive information is to not send it to the client at all.

Rules

Do
Use a secret for a value someone might not want visible by default, like an account number.Set name to group related secrets so revealing one conceals the others.Set block for a secret that wraps a larger piece of content, like a paragraph or image.
Don't
Don't treat a secret as a security boundary — the concealed content is still in the DOM and page source.Don't use a secret for content that's fine to always show — it adds an interaction step with no benefit.

Basic usage

Content stays concealed until a user clicks the reveal button.

A secret concealing inline content until revealed.

PreviewCode
<div class="pt-xlarge">
  <forge-secret name aria-label="secret">
    Secret content here
  </forge-secret>
</div>

Named groups

Give multiple secrets the same name and they behave like a radio group — revealing one conceals any other open secret sharing that name.

Secrets sharing a name, so revealing one conceals the others.

PreviewCode
<div class="flex flex-col gap-medium pt-xlarge">
  <forge-secret name="secrets" aria-label="secret">
    Lorem ipsum
  </forge-secret>
  <forge-secret name="secrets" aria-label="secret">
    Dolor sit amet
  </forge-secret>
  <forge-secret name="secrets" aria-label="secret">
    Consectetur adipiscing elit
  </forge-secret>
</div>

Block layout

Set block for a secret that wraps a larger piece of content, like a paragraph or image, instead of displaying inline with surrounding text.

A block secret concealing a larger piece of content.

Roles and states

forge-secret uses role="group" to semantically group its content with the reveal button. The button carries aria-expanded to convey whether the content is currently visible, and aria-controls to associate it with the group. When content is revealed, that change is announced to screen readers through a live region. While concealed, the content is marked inert so it can’t receive keyboard focus or be read by assistive technology.

Keyboard interaction

The reveal button is focusable and can be toggled with Enter or Space. Pressing Escape while a secret is open closes it. Clicking the concealed content itself also reveals it and moves focus to the button.
